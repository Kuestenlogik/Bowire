{%- comment -%} Renders a screenshot that has a dark and a light variant as ONE , in AVIF and WebP at 400 and 1200 px (#969). Usage: {% include themed-img.html src="/assets/images/screenshots/streaming.png" alt="Streaming response — Wireshark-style frame list" class="some-extra-class" %} `src` is the *theme-less* name ending in `.png`. The files used are the variants scripts/site/optimize-images.mjs writes next to `…-dark.png` and `…-light.png`: `…-dark-400w.avif`, `…-dark-1200w.webp`, and so on. The dark sources come first and carry `media="(prefers-color-scheme: dark)"`, so without script the system preference picks the variant. When the visitor chooses a theme with the toggle, main.js sets that `media` to `all` or `not all` and the browser selects again. Only the variant on screen is ever downloaded; the two tags this include used to render fetched both. `sizes` (optional) overrides the default slot width. {%- endcomment -%} {%- assign extra_class = include.class | default: "" -%} {%- assign stem = include.src | replace: ".png", "" -%} {%- assign sizes = include.sizes | default: "(min-width: 800px) 1200px, 100vw" -%} {%- assign variants = "dark,light" | split: "," -%} {%- assign formats = "avif,webp" | split: "," -%} {%- for variant in variants -%} {%- for format in formats %} {%- endfor -%} {%- endfor %}
