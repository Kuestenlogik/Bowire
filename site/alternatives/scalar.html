When each fits, where they differ, and how both read the same OpenAPI document. lede: Scalar renders an OpenAPI document into beautiful docs. Bowire discovers the contract from the running service, across every protocol it speaks. Many teams use both. ---

There is nothing to migrate: Bowire reads the same OpenAPI document Scalar renders.

  • Standalone: bowire --url=https://api.example.com/openapi.json — the exact document URL, JSON or YAML, OpenAPI 3 or Swagger 2.0. See REST / OpenAPI.
  • Embedded: app.MapBowire() in the ASP.NET app reads the same metadata Microsoft.AspNetCore.OpenApi uses, so the workbench never runs on a stale spec.
  • A file on disk: drop it on the Schema Files tab.

Keep Scalar for the public docs site and use Bowire for development, testing and the protocols beyond REST.
