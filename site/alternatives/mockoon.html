--- layout: alternative tool: mockoon title: A Mockoon alternative for gRPC, SSE and MQTT mocks — Bowire description: Bowire vs. Mockoon — when each fits, where they differ feature by feature, and how to run a Mockoon API as a Bowire mock through its OpenAPI export. Apache 2.0. lede: Mockoon builds HTTP and WebSocket mocks by hand in a GUI. Bowire records real traffic and replays it as a mock over gRPC, SSE, WebSocket, MQTT and more — or synthesises one from a schema. ---

Mockoon exports an environment as OpenAPI v3 JSON, and Bowire's mock server serves an OpenAPI document directly:

bowire mock --schema mockoon-export.json --port 7070

Every operation becomes a mock step whose body is generated from the declared response schema. Mockoon's templating, rules and data buckets don't carry over; add --chaos for latency and failures, or --stateful to walk a scenario. See schema-only mock.

The other way in is a recording: capture a session against the real service in Bowire, and bowire mock --recording session.bwr replays it, streaming protocols included. See mock server.
