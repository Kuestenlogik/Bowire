--- layout: alternative tool: insomnia title: An Insomnia alternative for multi-protocol services — Bowire description: Bowire vs. Insomnia — when each fits, where they differ feature by feature, and how to import your Insomnia collections and environments. Local-first, Apache 2.0. lede: Insomnia is a polished desktop client from Kong. Bowire discovers your services instead of keeping a hand-maintained collection, speaks more protocols, and needs no account. ---

Bowire imports Insomnia exports directly: the v5 collection file (YAML) and the older v4 export (JSON or YAML). Right-click Collections in the Workspaces tree and choose Import files…, or run bowire import insomnia.yaml.

  • What comes across: requests with their folders, headers, query parameters and bodies; sub-environments with the base environment merged in; {% raw %}{{ _.var }}, {% uuid %} and {% now %}{% endraw %} as Bowire variables; Bearer, Basic and API-key auth as headers.
  • What the import report names: scripts, {% raw %}{% response %}{% endraw %} tags, OAuth 2 / IAM / Digest / NTLM auth (set them on the Bowire environment), gRPC and WebSocket requests, and credentials that sit in clear text.
  • Or skip the import and point Bowire at the running service — discovery covers OpenAPI, gRPC and GraphQL.

The migration guide lists what maps one-to-one, what changes shape, and what has no equivalent.
