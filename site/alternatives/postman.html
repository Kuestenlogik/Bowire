Local-first, no account, Apache 2.0. lede: Postman is the default API client for cloud teams. Bowire covers the protocols Postman doesn't, runs locally without an account, and can live inside your ASP.NET service. ---

Bowire imports Postman Collection v2.1 JSON directly. In Postman, export the collection (Collection v2.1), then open the Compose rail in Bowire and click Import Postman.

  • Method, URL, headers and raw body carry over; nested folders are flattened into one list.
  • {% raw %}{{variable}}{% endraw %} placeholders become Bowire's ${variable}. Define the same names in a Bowire environment and the collection runs as is.
  • Pre-request scripts and Postman tests are not converted. Re-create checks as Bowire assertions.

For gRPC, GraphQL and OpenAPI services you often don't need the collection at all: point Bowire at the running service and it discovers every method. Details: Postman Collection import.
