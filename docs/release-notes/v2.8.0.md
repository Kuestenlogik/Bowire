---
title: A workbench in two languages and several panes, a test pillar that reaches CI, and a Bowire that knows the others
version: 2.8.0
---

2.8 is the release in which the workbench stops assuming one of everything: one language, one live method, one Bowire. It speaks German and English throughout, holds two methods open side by side, and one Bowire can list a whole fleet of others. The test pillar reaches the pipeline — design-time lint, snapshot approval and contract suites run from `bowire test` — and MCP, parallel sessions and a new scaffolder round out the agent side.

## Localisation and layout

### German and English, all the way down

Every string of the workbench goes through the translation layer now, with German and English catalogues shipped side by side and a parity test that fails a build where the two drift apart — a key missing, or a placeholder dropped or invented ([#117](https://github.com/Kuestenlogik/Bowire/issues/117)). The language follows the browser until one is picked under Settings → General. Walking the workbench under a pseudo-locale after the sweep turned up strings that no screenshot could catch — a bundle outside the workbench scope whose translations threw before they rendered, among them — and those are fixed at their root, not per string. Plugin settings and protocol descriptions, which arrive from the backend, are covered as well ([#691](https://github.com/Kuestenlogik/Bowire/issues/691)), and the action log stores keys rather than the English sentence it happened to render ([#689](https://github.com/Kuestenlogik/Bowire/issues/689)).

### Two methods at once

Request and response state used to live in globals, so only one method could ever be live ([#695](https://github.com/Kuestenlogik/Bowire/issues/695)). With that gone, a tab can split its request and response (automatic, by drag or by shortcut, remembered per tab), and two tabs can sit side by side in panes, each streaming into its own view with its own state ([#250](https://github.com/Kuestenlogik/Bowire/issues/250)). Wiring that waited for an animation frame never ran in a hidden tab; it does now ([#696](https://github.com/Kuestenlogik/Bowire/issues/696)). Popping a pane out into its own window follows as [#753](https://github.com/Kuestenlogik/Bowire/issues/753).

### A shelf for what you carry between surfaces

The visual shelf is a holding area next to the operating system's clipboard: right-click a value — a response field, an environment variable — and it waits on the shelf, typed, until it is dropped where it is needed ([#251](https://github.com/Kuestenlogik/Bowire/issues/251)). Building it turned up a bug older than the shelf: the first click into any text field that had never had focus was lost, because the variable-chip overlay re-parented the field on focus ([#706](https://github.com/Kuestenlogik/Bowire/issues/706)).

### Header sets, and names or paths

Headers can be kept as named, scoped sets and switched on and off instead of retyped ([#95](https://github.com/Kuestenlogik/Bowire/issues/95)), and the sidebar shows methods by name or by path, as the operator prefers ([#47](https://github.com/Kuestenlogik/Bowire/issues/47)).

## The test pillar reaches CI

### Design-time lint

The schema linter learned naming and PII rules and shows its findings inline next to the method, and `bowire test --suite lint` puts them into the test runner's reports — JUnit with one test case per rule, SARIF with the service, method and field as the location — without failing a pipeline on its first run ([#583](https://github.com/Kuestenlogik/Bowire/issues/583)). Response-shape rules could never fire on REST, because discovery populated no output fields; they can now ([#663](https://github.com/Kuestenlogik/Bowire/issues/663)).

### Snapshots, data, faults, contracts

A snapshot diff can be reviewed and approved in the workbench, against the same baseline CI compares with; data-driven runs get a results view; and the mock can drop frames on purpose to test what a client does when they go missing ([#366](https://github.com/Kuestenlogik/Bowire/issues/366)). `bowire test --workspace-id <id>` runs a workspace's stored suite, and `bowire workspace list` names the ids ([#365](https://github.com/Kuestenlogik/Bowire/issues/365)).

## MCP, agents and the assistant

### MCP tools stream

A tool call no longer waits in silence: progress notifications and log messages from the server arrive while it runs, and the result is the last frame ([#46](https://github.com/Kuestenlogik/Bowire/issues/46)). The MCP forwarding over HTTP starts again and `--attach` finds the standalone server where it listens ([#730](https://github.com/Kuestenlogik/Bowire/issues/730), [#731](https://github.com/Kuestenlogik/Bowire/issues/731)).

### A Bowire that knows the others

Bowires embedded across a fleet can register with a hub (`Bowire:Agent:HubUrl`), which lists them with a link to each one's own workbench and serves them as a catalogue for other Bowires ([#128](https://github.com/Kuestenlogik/Bowire/issues/128)). Agents push: the hub never has to reach them, and a restarted hub is whole again after one heartbeat. The hub also offers the agents tagged `parallel-executor` as executors for parallel sessions.

### Parallel sessions you can expose

An executor listens beyond loopback, which made it a load generator for whoever could reach it. It now takes a target allowlist and a token, a coordinator can refuse to send anything to an executor in clear text, and both sides write a hash-chained audit log that joins a run to what each executor did ([#313](https://github.com/Kuestenlogik/Bowire/issues/313)).

### A service from a sentence

"REST CRUD for User with email + role" becomes a schema, a runnable C# stub, a workbench collection and a smoke test that passes against the stub as generated ([#177](https://github.com/Kuestenlogik/Bowire/issues/177)). The assistant — a local model first — writes only the entity spec; the files come from checked-in templates, so a spec gives the same code with any model or none, and a deterministic parser reads the sentence when no model answers.

## Protocols and plugins

### GraphQL as a full client

GraphQL closes the distance between discovery and a real client ([#710](https://github.com/Kuestenlogik/Bowire/issues/710)): queries over GET, automatic persisted queries, batching, multipart file uploads with a file input in the request builder, and multiplexing several operations over one socket ([#713](https://github.com/Kuestenlogik/Bowire/issues/713), [#715](https://github.com/Kuestenlogik/Bowire/issues/715)). The stream contract has one error shape now instead of one per plugin ([#712](https://github.com/Kuestenlogik/Bowire/issues/712)).

### The schema as a graph

The Schema Designer draws a discovered schema's type graph — which message uses which, for the `.proto` with fifty types where a tree cannot answer that — and ships as the first default-off rail module, switched on under Settings → Rail modes ([#247](https://github.com/Kuestenlogik/Bowire/issues/247), [#249](https://github.com/Kuestenlogik/Bowire/issues/249), [#711](https://github.com/Kuestenlogik/Bowire/issues/711)).

### Rails out of core, plugins that get what they declare

The remaining rails moved into their own packages, so core carries the discover, home and workspace surfaces and nothing else ([#311](https://github.com/Kuestenlogik/Bowire/issues/311)). A sidecar's manifest can name an interpreter that resolves through `PATH`, and its declared settings reach it ([#692](https://github.com/Kuestenlogik/Bowire/issues/692), [#693](https://github.com/Kuestenlogik/Bowire/issues/693)). gRPC discovery keeps a type referenced twice ([#694](https://github.com/Kuestenlogik/Bowire/issues/694)), and a service that imports `google/protobuf/empty.proto` can be called again. The AsyncAPI binding resolvers are implemented instead of throwing ([#357](https://github.com/Kuestenlogik/Bowire/issues/357)).

## Security

### Out-of-band callbacks in the workbench

The Security rail can generate a callback payload and watch the interactions arrive live, and the workbench's own SSRF probe now plants a callback per URL parameter instead of inferring the finding from a latency difference ([#486](https://github.com/Kuestenlogik/Bowire/issues/486)).

## Getting started

### Starting Bowire

Every platform gets a desktop shortcut, the workbench runs without a console window, and the docs say how to start it ([#685](https://github.com/Kuestenlogik/Bowire/issues/685)). Starting a second Bowire on a port the first already holds opens the running workbench instead of crashing ([#684](https://github.com/Kuestenlogik/Bowire/issues/684)). Uploaded schemas belong to their workspace and survive a restart, and `bowire discover --schema` hands the CLI a file directly ([#654](https://github.com/Kuestenlogik/Bowire/issues/654)).

### The site

The launch wizard and the quickstart set up the AI assistant as an optional step, with the same provider picker as Settings → AI ([#110](https://github.com/Kuestenlogik/Bowire/issues/110)); every quickstart path now ends on its finish flag ([#738](https://github.com/Kuestenlogik/Bowire/issues/738)); and the README, the workbench, the CLI (once, never in CI) and the site ask for a star and a watch ([#669](https://github.com/Kuestenlogik/Bowire/issues/669)).

## Fixes

- `el()` no longer turns `disabled: false` into a disabled control ([#686](https://github.com/Kuestenlogik/Bowire/issues/686)).
- The map host unmounts the widget it mounted; every re-render used to leak one ([#707](https://github.com/Kuestenlogik/Bowire/issues/707)).
- A mock emitter set to loop at replay speed 0 no longer publishes without bound ([#708](https://github.com/Kuestenlogik/Bowire/issues/708)).
- SignalR ad-hoc invoke takes the JSON array it always required ([#665](https://github.com/Kuestenlogik/Bowire/issues/665)); the method-name form on `/api/invoke` is the same for every plugin ([#664](https://github.com/Kuestenlogik/Bowire/issues/664)).
- Links from the docs with `?rail=` and `?topic=` open the rail and the topic they name ([#735](https://github.com/Kuestenlogik/Bowire/issues/735), [#736](https://github.com/Kuestenlogik/Bowire/issues/736)).
- No setting decides silently by assembly load order any more; a failed `/api/protocols` is shown instead of an empty settings page ([#751](https://github.com/Kuestenlogik/Bowire/issues/751), [#752](https://github.com/Kuestenlogik/Bowire/issues/752)).
- `plugin install` no longer suggests a re-run its own guard blocks ([#666](https://github.com/Kuestenlogik/Bowire/issues/666)).
- Console lines no longer carry the action log's exemption reason ([#739](https://github.com/Kuestenlogik/Bowire/issues/739)).
- Test infrastructure: an `InvokeEndpoints` fixture and replayer coverage, isolated test storage that no longer writes to the real `~/.bowire`, automated tests for the schema drop zone and the upload shortcut, and loopback test ports that look for foreign traffic instead of tolerating it ([#216](https://github.com/Kuestenlogik/Bowire/issues/216), [#714](https://github.com/Kuestenlogik/Bowire/issues/714), [#732](https://github.com/Kuestenlogik/Bowire/issues/732), [#733](https://github.com/Kuestenlogik/Bowire/issues/733), [#734](https://github.com/Kuestenlogik/Bowire/issues/734), [#737](https://github.com/Kuestenlogik/Bowire/issues/737), [#740](https://github.com/Kuestenlogik/Bowire/issues/740)).
- Test-pillar and request-builder polish for GraphQL layouts ([#292](https://github.com/Kuestenlogik/Bowire/issues/292)).
