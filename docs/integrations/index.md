# Integrations

Guides for running Bowire inside the tools you already use, feeding
traffic from them into Bowire, and wiring Bowire into existing pipelines.

- [VS Code](vscode.md) — the workbench in an editor panel, driving the
  same CLI your terminal and CI run. Where collections live, how the
  extension finds a Bowire (and fetches one if it finds none), and how it
  learns which port the workbench bound.
- [Playwright](playwright.md) — record a browser scenario as HAR, import
  it as a replayable recording / mock / test suite.
