# Bowire logos

Every file here is generated by the shared branding tool (`scripts/branding/tool/generate-logos.mjs`, a pinned copy of
`tools/branding` in the Kuestenlogik repository; see `scripts/branding/README.md`) from two drawings,
`scripts/branding/bowire_mark_source.svg` and `scripts/branding/bowire_emblem_source.svg`, configured in
`scripts/branding/brand.json`. Do not edit them by hand: the next run replaces them and deletes anything it did not
write, and `generate-logos.mjs --check` fails when they differ from the drawings.

PNGs come at 1x and @2x with a transparent background, each also as a lossless WebP. Use `adaptive` where a page
switches between light and dark, `colored` on light (Küstenlogik navy `#003e60` with Bowire's violet `#865bc4`), `white` on dark or on photos,
`black` for single-colour print.

## Icons

| File | Use |
|---|---|
| `favicon.svg`, `favicon.ico` | Tab icon: the mark cropped square, adaptive; the ICO at 16, 32 and 48 px. |
